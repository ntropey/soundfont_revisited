# SoundFont Revisited — Engineering Conventions

- License: `GPL-3.0-or-later`
- 100% client-side, offline-first, zero server tracking or telemetry.
- `@soundfont/core` has zero DOM or Node dependencies; all RIFF `.sf2` parsing, serialization, `.sfz` export, and demo synthesis are deterministic and pure TypeScript.
- Use American English spelling across code and documentation.
- Commit messages: `Area: summary` (lowercase after the colon).
